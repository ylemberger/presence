# תיקיית הצגה לאתר

כאן יש מערכת שנראית כמו מערכת הנוכחות האמיתית, עם נתונים לדוגמה (שמות בדויים).  
אין חיבור למסד האמיתי, לשכר, או לחשבונות אמיתיים.

## מה להעלות לאתר

העלי **רק** את התיקייה `site` (או את הקובץ `index.html` בתוכה).

אל תעלי:
- `.env` / `.env.local`
- את תיקיית `src` או `supabase`
- את שאר הפרויקט

## איך להציג

1. העלי את `index.html` לתיקייה באתר (למשל `/presence` או `/attendance`).
2. אם צריך — שניי את שם הקובץ ל־`index.html` בתיקייה הזו.
3. פתחי את הכתובת — נפתח ישר לוח הבקרה, בלי מסך כניסה.

אפשר גם לפתוח את `index.html` כפול במחשב, בלי שרת.

## מה יש בפנים

לוח בקרה, תלמידות, נוכחות, מבחני השלמה, מערכת שעות, שיעורים, מורות, דוחות והגדרות.  
סימונים נשמרים רק בדפדפן של מי שגולש (לא בענן).

ב«הגדרות» יש «איפוס לנתוני פתיחה» אם רוצים להתחיל מחדש.
